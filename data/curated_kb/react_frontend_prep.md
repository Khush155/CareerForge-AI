# React & Modern Frontend Engineering Guide

## Overview
Frontend engineering focuses on building responsive, accessible, and high-performance user interfaces with modern component architectures.

## Core Topics
1. **React 18/19 Core Principles**:
   - Component Lifecycle, Virtual DOM, and Reconciliation.
   - Core Hooks: `useState`, `useEffect` dependency hygiene, `useMemo`, `useCallback`, `useRef`.
   - Custom Hooks for encapsulating and reusing stateful logic.

2. **State Management & Data Fetching**:
   - Context API for lightweight global state.
   - Client-side caching & server state: TanStack Query (React Query) / SWR.
   - Optimistic UI updates and resilient error boundaries.

3. **Performance Optimization & Web Standards**:
   - Code-splitting with `React.lazy` and `Suspense`.
   - Web Vitals: Largest Contentful Paint (LCP), First Input Delay (FID) / Interaction to Next Paint (INP), Cumulative Layout Shift (CLS).
   - Accessibility (a11y): Semantic HTML, ARIA attributes, keyboard navigation.
